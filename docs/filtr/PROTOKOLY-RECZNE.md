# Protokoły ręcznych porównań z systemami państwowymi

Plan: `docs/koordynacja/PLAN-ZELAZNY-FILTR.md`, B4.7 pkt 5; decyzja D49.
Porównanie z e-mikrofirmą (VAT) i e-Płatnikiem (składki ZUS) robi księgowa albo
Bartosz raz w roku (przed nowym rokiem parametrów) i przy każdej zmianie
obliczeń VAT albo ZUS. Lista kontrolna: `docs/runbooks/filtr.md`, sekcja
„Środowiska testowe i testy mutacyjne”. Wpisy od najnowszego.

## Szablon wpisu

```
### RRRR-MM-DD: <e-mikrofirma | e-Płatnik>
- Wersja kodu (SHA z main):
- Kto porównywał:
- Zakres (ile ewidencji VAT albo które etapy ZUS):
- Różnice (pole, nasza wartość, wartość systemu, wyjaśnienie):
- Wynik: zgodne | różnice opisane w USTALENIA.md pod kodem:
```
